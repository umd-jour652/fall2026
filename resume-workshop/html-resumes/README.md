Resume Workshop - HTML Module

Complete setting up a basic resume using HTML

How to submit: Commit index.html to the resume folder in your GitHub repo. Post link to GitHub pages site in ELMS.

Getting started
Create a folder called “resume” in your GitHub repo (Documents > GitHub > repoName).
You'll need a headshot image as well. Save a JPG file of a headshot image in the "resume" folder in your GitHub repo (Documents > GitHub > repoName).
Open your preferred text editor (e.g., Brackets). Start a new file and save it as “index.html” in the resume folder in your repo.
Open index.html in Google Chrome.
When you make changes in index.html in your preferred text editor, refresh index.html in Chrome to see changes. This is critical. Get into the habit of making a single change, and refreshing in the browser to check it.
Periodically commit changes on GitHub Desktop and sync to main.
You'll need the word doc/text file with your written resume and a headshot (JPG).
Detailed instructions

When you're finished with this assignment, your resume should look essentially identical to the link at the bottom of this page. Pay close attention to the following guidelines:

Start by writing valid HTML boilerplate (DOCTYPE, etc. ...).
Title the page "[FirstName] [LastName]'s Resume" (e.g., "Hyon-Young Kim's Resume") using the <title> tag in the <head> section.
Use the following tags for each part of the resume:
Name: Heading 1
Title: Strong
Contact details (Email, LinkedIn, X, GitHub): Unordered list; your Email, LinkedIn, X, and GitHub should be linked to your profile on those sites.
Section Titles (Experience, Education, Skills): Heading 2
Job Titles: Heading 3
Job Organization: Heading 4
Job Dates: Heading 5
Job Description: Paragraph tags
Education: Unordered list
Skills: Unordered list
Add your photo below your name and title. Make it 300 pixels wide.
In writing code, use proper indentation and spacing.
Put one HTML comment right after the open body tag saying "I built this myself!"
